# 💹 Hướng dẫn mở excel khi bị lỗi

Khi mở file excel mà bị hiện tượng như hình:

<img src=".gitbook/assets/Nguyên nhân gây ra lỗi không mở được file Excel" alt="Nguyên nhân gây ra lỗi không mở được file Excel" height="335" width="625">

Vì file định dạng đuôi .xls mới có thể mở ở các phiên bản Excel đời thấp hơn. Để mở file có các định dạng đuôi .xlsx thì cần cài đặt các phiên bản mới hơn của Microsoft Office để có thể mở được file.

<img src=".gitbook/assets/Cài đặt phiên bản mới hơn" alt="Cài đặt phiên bản mới hơn" height="360" width="641">

### Sử dụng tính năng tự động sửa lỗi

**Bước 1:** Mở file Excel hoàn toàn mới, cách mở: Tìm mục File và chọn Open > Chọn Browse.

<img src=".gitbook/assets/tìm mục File  Open  Browse." alt="tìm mục File > Open > Browse." height="372" width="662">

**Bước 2:** Sau đó,tìm đến file Excel muốn khôi phục. Chú ý vào biểu tượng tam giác cạnh phần Open, mở thêm sẽ thấy tính năng Open and Repair.

<img src=".gitbook/assets/Open and Repair" alt="Open and Repair" height="354" width="629">

**Bước 3:** Xuất hiện hộp thoại thông báo của Microsoft Excel các bạn ấn vào phần Repair để sửa chữa tập tin bị lỗi.

<img src=".gitbook/assets/Xuất hiện hộp thoại thông báo của Microsoft Excel các bạn ấn vào phần Repair để sửa chữa tập tin bị lỗi." alt="Xuất hiện hộp thoại thông báo của Microsoft Excel các bạn ấn vào phần Repair để sửa chữa tập tin bị lỗi." height="322" width="600">

Hoặc chọn Extract Data nhằm mục đích trích lấy dữ liệu bên trong file excel nếu đang có việc cần xử lý gấp mà phần mềm không thể mở ra được.

<img src=".gitbook/assets/Extract Data nhằm mục đích trích lấy dữ liệu bên trong file excel nếu đang có việc cần xử lý gấp mà phần mềm không thể mở ra được" alt="Extract Data nhằm mục đích trích lấy dữ liệu bên trong file excel nếu đang có việc cần xử lý gấp mà phần mềm không thể mở ra được" height="326" width="607">

### **3. Vô hiệu hóa Protected View**

Đây là cách mà nhiều người sử dụng đã áp dụng. Vô hiệu hóa ” Protected View” (chế độ xem được bảo vệ) có thể gây hại cho máy tính. Nó sẽ tăng cao khả năng bị đe dọa từ các lỗ hổng bảo mật. Để đảm bảo an toàn, bạn nên lưu file của mình thành 2 bản trước khi thực hiện điều này.

**Bước 1:** Mở Microsoft Excel và chọn File > Chọn Options.

<img src=".gitbook/assets/Mở Microsoft Excel và chọn File  Chọn Options" alt="Mở Microsoft Excel và chọn File > Chọn Options" height="324" width="604">

**Bước 2:** Chuyển đến Trust Center > Chọn Trust Center Settings.

<img src=".gitbook/assets/Chuyển đến Trust Center  Chọn Trust Center Settings" alt="Chuyển đến Trust Center > Chọn Trust Center Settings" height="324" width="605">

**Bước 3:** Chuyển đến Protected View, bỏ chọn tất cả các hộp > Nhấp vào OK.

<img src=".gitbook/assets/Chuyển đến Protected View, bỏ chọn tất cả các hộp  Nhấp vào OK" alt="Chuyển đến Protected View, bỏ chọn tất cả các hộp > Nhấp vào OK" height="326" width="608">

**Bước 4:** Khởi động lại Microsoft Excel. Bây giờ, file Excel của bạn đã có thể truy cập bình thường. Hãy thử mở lại nó để kiểm tra.

### **4. Mở khóa file**

Đôi khi, có những file đã bị khóa từ trước. Nếu lỗi file Excel không mở được là do file bị khóa, bạn có thể mở khóa chúng ra như sau:

**Bước 1:** Tìm và nhấp chuột phải vào file bạn không thể mở > Chọn Properties.

<img src=".gitbook/assets/Bước 1 Tìm và nhấp chuột phải vào file bạn không thể mở  Chọn Properties." alt="Bước 1: Tìm và nhấp chuột phải vào file bạn không thể mở > Chọn Properties." height="326" width="607">

**Bước 2:** Trong tab General, chọn hộp bên cạnh Unlock > Nhấp vào Apply > Chọn OK.

<img src=".gitbook/assets/Trong tab General, chọn hộp bên cạnh Unlock  Nhấp vào Apply  Chọn OK." alt="Trong tab General, chọn hộp bên cạnh Unlock > Nhấp vào Apply > Chọn OK." height="399" width="604">
