# 🤙 Hướng dẫn backup và khôi phục zalo PC

***

### 1. Hướng dẫn backup zalo PC theo file

Cách backup này sẽ giữ được nguyên các file có trên máy tính và dễ dàng chuyển zalo từ máy tính này sang máy tính khác

**Bước 1:** Vào this PC trên desktop hoặc trình quản lý file của window, truy cập đường dẫn C:\Users\\\[User của bạn]\AppData\Roaming\ZaloData

<figure><img src="../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>

ở đây user là dpham, các máy khác sẽ có các tên khác nhau.

**Bước 2:** chọn tất cả các file bằng chuột hoặc crtl + A để chọn hết file, sau đó copy ra một thư mục mới, vậy là hoàn thành back up

### 2. Hướng dẫn khôi phục zalo PC thông qua bản backup.

**Bước 1:** chuẩn bị sẵn file backup zalo, chọn hết tất cả các file đó -> copy hết tất cả các file

**Bước 2:** Tiếp tục truy cập đường dẫn C:\Users\\\[User của bạn]\AppData\Roaming\ZaloData

<figure><img src="../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

**Bước 3:** Ctrl + A hết các file ở đó, Ctrl + V để replace các file backup

**Bước 4:** Vào zalo để đăng nhập lại, lúc đó data sẽ quay trở lại.
