# 📧 Hướng dẫn cài đặt chữ ký Outlook

**Bước 1:** Vào outlook, chọn file -> option

***

Chọn mail -> signatures

<img src="../.gitbook/assets/unknown (37).png" alt="" height="503" width="624">

\
\
\
<br>

**Bước 2:** Đối với máy mới, chọn new, sau đó điền tên của chữ kí đó ( ví dụ ở đây là test)

**Bước 3:** Đối với nhân viên đã có chữ kí cũ cần sửa, tại ô Select signature to edit, chọn chữ kí cần sửa

<img src="../.gitbook/assets/unknown (38).png" alt="" height="507" width="624">

**Bước 4:** Sau khi nhấn vào chữ kí cần sửa rồi, tiến hàng sửa chữ kí trên ô edit signature

<img src="../.gitbook/assets/unknown (39).png" alt="" height="528" width="624">

Với mục khu vực Choose default signature, có 2 mục cần chọn là New Messages và Replies/Forwards, cả 2 mục đó đểu chọn chữ kí vừa cài đặt ( ví dụ ở đây chọn test vì trước đó chữ kí được đặt tên là test )

Cuối cùng nhấn ok để lưu lại

<br>
